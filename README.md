# LostMedia Grabber Pro

A simple tool to pull media and image URLs straight from the Wayback Machine.

### Quick Setup (Trial Version)

1. Grab the `.zip` file from the **Releases** tab on the right.
2. Unzip the folder on your computer.
3. Open Chrome and go to `chrome://extensions/`.
4. Turn on **Developer mode** (top right toggle).
5. Click **Load unpacked** and select your unzipped folder. You're good to go!
