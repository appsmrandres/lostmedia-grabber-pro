# LostMedia Grabber Pro

A simple tool to pull media and image URLs straight from the Wayback Machine. Now completely free and open-source.

### Quick Setup

#### For the Chrome Extension:
1. Grab the extension .zip file from the Releases tab on the right.
2. Unzip the folder on your computer.
3. Open Chrome and go to chrome://extensions/.
4. Turn on Developer mode (top right toggle).
5. Click Load unpacked and select your unzipped folder.

#### For the Desktop App (Windows):
1. Grab the desktop .zip file from the Releases tab on the right.
2. Unzip the folder (make sure the _internal folder stays in the same place as the .exe).
3. Run the executable file to start using the app.
